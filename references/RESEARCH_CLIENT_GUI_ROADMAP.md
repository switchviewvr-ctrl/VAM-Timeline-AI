# Research Client GUI Roadmap

The v0 research client is a static, read-only dashboard for semantic research artifacts.

It shows:
- current runs
- ontology files
- lexicon and web-context reports
- explicit safety status

It does not edit data, save labels, run ML, or export Timeline clips.

Output:
- `data/runs/research_client_v0/index.html`

The future GUI should remain a review and navigation tool until the ontology, controller mapping, and generation guardrails are manually accepted.
