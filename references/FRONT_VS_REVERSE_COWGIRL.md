# Front vs Reverse Cowgirl

Lean direction and facing direction are different semantic fields.

Frontal Cowgirl can include:

- upright torso
- forward lean
- backward lean
- hands forward support
- hands behind support

Reverse Cowgirl should only be used when orientation/facing evidence indicates the rider is facing away from the partner. A backward torso lean alone is not enough to infer reverse Cowgirl.

Prompt planning follows the same rule: `lean back cowgirl` remains `front_cowgirl`; only an explicit phrase such as `reverse cowgirl` requests `reverse_cowgirl`.
